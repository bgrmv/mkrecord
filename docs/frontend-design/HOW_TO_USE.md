# Как использовать Frontend Design Skill

## Быстрый старт

### Шаг 1: Структура подключена
В проекте уже есть:
- `.claude-plugin/plugin.json` — конфигурация плагина
- `docs/frontend-design/SKILL.md` — подробное описание принципов

### Шаг 2: Просто используй ключевые слова

Напиши промпт с упоминанием дизайна:

```
"Улучши UI компонента Header с camera-aesthetic"
"Переработай styling portfolio-cards, сделай визуально distinctive"
"Создай новый компонент intro-screen с bold дизайном"
```

### Шаг 3: Я применю skill автоматически

Когда я вижу ключевое слово (`дизайн`, `UI`, `styling`, `interface`, etc.), я:
1. Прочитаю `docs/frontend-design/SKILL.md` для контекста
2. Применю принципы distinctive design
3. Создам production-ready код с bold aesthetic choices
4. Избегу generic AI-интерфейсов

## Примеры промптов

### ✅ Хорошие промпты (skill сработает)

```
"Переработай Header компонент. Дизайн должен напоминать кино-камеру с винтажной эстетикой"
```

```
"Улучши visual оформление видео-карточек. Добавь интересные hover-эффекты и depth"
```

```
"Создай UI для About раздела. Контекст: portfolio filmmakers. Нужен distinctive дизайн"
```

### ❌ Что не сработает (нужны ключевые слова)

```
"Исправь баг в компоненте" ← нет слов про дизайн/UI
"Добавь функциональность" ← не про визуал
```

## Настройка под твой проект

### Твой бренд: Camera + Filmmaker Portfolio

**Как использовать skill в контексте:**

1. **Упомяни контекст в промпте**:
   ```
   "Сделай UI компонента, как будто это кинокамера/кинопленка"
   ```

2. **Упомяни ключевые слова**:
   ```
   "Улучши дизайн (или styling/UI) видеоплеера с кинематографическими эффектами"
   ```

3. **Я буду применять**:
   - Aspect ratios видео (16:9, 4:3)
   - Винтажную палитру (темные, кинематографические цвета)
   - Киноэффекты (fade, iris, zoom, grain)
   - Монолитные шрифты киноискусства
   - Фокус и глубину в композиции

## Вопросы?

Если skill не сработал:
1. Проверь, что в промпте есть ключевое слово (дизайн, UI, styling, interface, etc.)
2. Описал ли ты контекст достаточно подробно?
3. Может быть, задача чистто функциональная (без визуального компонента)?

Если результат не соответствует ожиданиям:
- Добавь больше деталей о желаемом aesthetic
- Упомяни camera-theme более явно
- Дай примеры или вдохновение (тон, палитра, стиль)
