# Frontend Design Skill

## Описание

Skill автоматически активируется при упоминании в промптах ключевых слов, связанных с дизайном и интерфейсом. Помогает создавать **distinctive, production-grade фронтенд** с смелыми эстетическими решениями вместо типовых AI-интерфейсов.

## Когда активируется

Skill срабатывает, когда в промпте используются такие ключевые слова:

- **Английские**: `дизайн`, `UI`, `interface`, `component`, `styling`, `aesthetic`
- **Русские**: `визуальный`, `верстка`, `стилизация`

Примеры:
```
"Улучши дизайн кнопок в компоненте Header"
"Создай интересный UI для portfolio раздела"
"Переработай styling видеоплеера с aesthetic камеры"
```

## Ключевые принципы

### 1. Установи эстетическое направление
Перед кодом определи смелое визуальное направление:
- **Цель** — для кого и зачем этот интерфейс?
- **Тон** — минималистичный, максималистичный, экспериментальный?
- **Ограничения** — бренд, технические возможности, performance
- **Отличие** — что запомнится пользователю?

### 2. Типография
✅ **Выбирай красивые и интересные шрифты**
- Используй Google Fonts, Adobe Fonts, или специализированные шрифты
- Рассмотри display-шрифты для заголовков
- Убедись в читаемости на разных размерах

❌ **Избегай**:
- Arial, Helvetica, Inter (перегруженные)
- Типовые комбинации (Montserrat + Open Sans)

### 3. Цвет и тема
✅ **Коммитируй к связной палитре**
- Доминирующий цвет (главная идея)
- Акцентный цвет (контраст и внимание)
- Neutral цвета (фон, текст, границы)

❌ **Избегай**:
- Плоских материиал-дизайн палиток
- Случайной комбинации цветов
- Избытка контраста без целей

### 4. Анимация и движение
✅ **Используй CSS анимации для high-impact моментов**:
- Hover-эффекты на интерактивные элементы
- Scroll-триггеры для появления элементов
- Transition для плавных смен состояния
- Parallax, морфинг, rotate для камера-эстетики

❌ **Избегай**:
- Беспричинные анимации
- Слишком быстрые/медленные переходы
- Микросекундные задержки, снижающие UX

### 5. Пространственная композиция
✅ **Создавай напряжение и динамику**:
- Асимметричные layouts вместо grid
- Overlap и negative space
- Неожиданные размещения элементов
- Диагональные линии и углы

❌ **Избегай**:
- Идеальной симметрии везде
- Скучных равномерных сеток
- Предсказуемых расположений

### 6. Визуальные детали
✅ **Создавай атмосферу через**:
- Градиенты и текстуры
- Shadows и depth
- Contextual effects (для фильм-проекта: киноэффекты)
- SVG иллюстрации, паттерны

❌ **Избегай**:
- Плоского дизайна без глубины
- Слишком много эффектов (информационный шум)
- Generic иконок без переработки

## Применение к mkrecord

Для твоего камера-ориентированного портфолио:

### Главная идея
**Camera Roll Interface** — интерфейс выглядит как кино-камера, кадр пленки или окуляр

### Элементы для усиления
- **Aspect ratios** — 16:9, 4:3, 35mm film ratios
- **Фокус и глубина** — зависит от distance to objects
- **Кинематографические переходы** — fade to black, iris shot, zoom
- **Светлые рамки** — винетирование, grain эффект
- **Типография** — шрифты киноискусства (Optima, Trajan, Copperplate)

## Примеры использования

### Пример 1: Улучшение Portfolio раздела
```
Улучши визуальный дизайн portfolio-cards компонента.
Сделай его более кинематографическим с эффектом глубины и камеры.
Использовать aspect ratio видео (16:9) и добавить hover-анимацию,
как будто фокусируется камера.
```

### Пример 2: Переработка Header
```
Переработай Header компонент с camera-aesthetic.
Дизайн должен напоминать винтажную кино-камеру:
- Использовать темную палитру
- Добавить граммофонный эффект (виньетирование)
- Делай текст похожим на кинолабель
```

### Пример 3: Новый компонент с дизайном
```
Создай новый компонент для отзывов с distinctive дизайном.
Контекст: это filmmakers, которые смотрят проект.
Нужен UI, который выглядит как real cinema feedback card.
```

## Как работать со скиллом

1. **Просто упомяни слово** вроде "дизайн", "UI", "styling" в промпте
2. **Опиши что ты хочешь** — что улучшить, какой контекст, какое настроение
3. **Я автоматически**:
   - Выберу смелое визуальное направление
   - Применю эти принципы к коду
   - Создам distinctive, production-ready компонент

## Результат

Ты получаешь не просто working компонент, а **distinctive, memorable interface**, который:
- Соответствует твоему камера-бренду
- Имеет bold визуальные решения
- Готов к production
- Трудно копировать (не типовой AI код)
